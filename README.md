## 📌 Project Overview
This project is a responsive, single-page developer portfolio created as part of the Portfolio course activity. It serves as a showcase for personal engineering projects, technical skills, and continuous learning milestones.

---

## 🛠️ Tech Stack & Concepts
This application was built using a modern full-stack frontend ecosystem to ensure fast performance, strong type safety, and clean UI design:

* **React 19:** Powers the component-based user interface using the latest React features and standards.
* **TypeScript:** Provides strict static typing across components and data files to ensure maintainable, error-free code.
* **TanStack Start:** Framework utilized for modern routing, server-side capabilities, and optimized full-stack application structure.
* **Vite:** Acts as the build tool and local development server, providing fast Hot Module Replacement (HMR).
* **Tailwind CSS v4:** Used for styling and responsive utility-first design layout across desktop and mobile views.
* **Lucide React:** Icon collection integrated for consistent visual UI elements.

---

## 📂 Project Structure & Implementation

* **Data-Driven Architecture:** All personal information—including skill sets, project entries, and learning logs—is managed in a single structured data file (`src/data/portfolio.ts`).
* **Testing & Linting:** Includes support for unit testing with **Vitest** and code quality enforcement with **ESLint** and **Prettier**.
